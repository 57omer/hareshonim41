# הראשונים 41 – ממשק סיור לאתר

אתר סטטי: אין שרת, אין בסיס נתונים ואין שלב בנייה. מעלים את התיקייה כמו שהיא.

## מה בתיקייה
- `index.html` – הממשק כולו (עיצוב וקוד בתוך הקובץ).
- `embed-example.html` – דוגמה חיה לשילוב בתוך עמוד, כולל כפתורים של האתר שפותחים דירות.
- `media/hd/` – סרטונים ב‑1080p למחשב. `media/sd/` – 720p לטלפונים ולחיבור חסכוני.
- `data/` – סימון כל דירה לכל פריים (`hot_*.json`) ומסלול המצלמה למפה (`path_*.json`).
- `img/` – תמונת פתיחה ותוכניות הדירות למפה.
- `_headers` – הגדרות מטמון ל‑Netlify / Cloudflare Pages (באחסון אחר אפשר להתעלם).

## שלב 1 – העלאה
1. מעלים את כל התיקייה לאחסון סטטי: Netlify, Vercel, Cloudflare Pages, S3 + CloudFront, או תיקייה בשרת האתר (למשל `/tour/`).
2. הדף חייב לרוץ מ‑`https://`. פתיחה ישירה של הקובץ מהדיסק לא תטען את הסרטונים.
3. בודקים מגבלת גודל קובץ באחסון: הקובץ הגדול ביותר הוא `media/hd/exterior.mp4` (כ‑52MB). כל התיקייה כ‑215MB.
4. פותחים את הכתובת ובודקים במחשב ובטלפון.

## שלב 2 – חיבור לאתר
**כעמוד מלא** – קישור או כפתור באתר אל `https://הכתובת/index.html`. זו הדרך הפשוטה והטובה ביותר לטלפון.

**בתוך עמוד קיים** – מעתיקים את התגית:
```html
<iframe src="https://הכתובת/index.html?title=0" title="סיור בבניין ובדירות"
        style="width:100%;aspect-ratio:16/9;min-height:420px;border:0"
        allow="fullscreen" allowfullscreen loading="lazy"></iframe>
```
- בתוך עמוד, במחשב, הגלגלת שייכת לעמוד עד שלוחצים על הסיור ("לחצו כדי להפעיל את הסיור"), וחוזרת לעמוד כשהעכבר יוצא ממנו. כך הסיור לא "בולע" את גלילת העמוד.
- כפתור מסך מלא מופיע בפינה (דורש `allowfullscreen` בתגית).
- בטלפון מומלץ לתת ל‑iframe גובה של כמעט מסך מלא (`height:92vh`), או לקשר לעמוד המלא.

## פרמטרים בכתובת
| פרמטר | מה עושה |
|---|---|
| `?flat=p` / `5s` / `5n` / `g` | נפתח ישר לתוך הדירה (פנטהאוז / 5 חדרים דרום / 5 חדרים צפון / דירת גן) |
| `?title=0` | מסתיר את כותרת הפרויקט (כשלאתר יש כותרת משלו) |
| `?q=hd` / `?q=sd` | כופה איכות 1080p / 720p (ברירת מחדל: בחירה אוטומטית) |
| `?embed=1` / `?embed=0` | כופה או מבטל התנהגות "בתוך עמוד" |

אפשר לשלב: `index.html?flat=p&title=0`. כך כפתור "לסיור בפנטהאוז" באתר מוביל ישר לדירה.

## שליטה מהאתר (לא חובה, למתכנת האתר)
```js
// לפתוח דירה / לחזור לבניין
iframe.contentWindow.postMessage({ source: 'tour41', action: 'enter', flat: 'p' }, '*');
iframe.contentWindow.postMessage({ source: 'tour41', action: 'exit' }, '*');
// לדעת מה מוצג
addEventListener('message', e => { if (e.data && e.data.source === 'tour41') console.log(e.data.event, e.data.mode, e.data.flat); });
```
דוגמה עובדת: `embed-example.html`.

## טעינה
קודם נטען סרטון החוץ בלבד והממשק נפתח. סרטוני הדירות נטענים ברקע אחד אחרי השני;
כניסה לדירה שעוד לא נטענה מציגה אחוזי טעינה וממתינה.

## הוספה או עדכון של דירה
ב‑`index.html`, ברשימת `TOURS`: שורה עם מזהה, שם קובץ, אורך סרטון המקור, זמן הכניסה האוטומטית והכיתובים;
ולצידה קובץ וידאו בשתי האיכויות, `data/hot_<id>.json`, ואם יש מפה – `data/path_<id>.json` והגדרת מפה.
פרטי הדירה שבכיתוב (שם, קומה, כיוון) נמצאים באותה שורה, בשדות `name` ו‑`info`.
